# User stories

| ID | En tant que… | Je veux… | Afin de… | Priorité |
| --- | --- | --- | --- | --- |
| US01 | Responsable e-commerce | voir le nombre de sessions à chaque étape du parcours | repérer l'étape où l'on perd le plus de visiteurs | Must |
| US02 | Responsable e-commerce | voir le taux d'abandon entre deux étapes | savoir où concentrer les efforts | Must |
| US03 | Responsable acquisition | comparer le taux de conversion par canal | savoir quels canaux privilégier | Must |
| US04 | Responsable e-commerce | comparer la conversion sur mobile et sur ordinateur | décider d'améliorer ou non l'expérience mobile | Must |
| US05 | Responsable e-commerce | filtrer par période | suivre l'évolution mois par mois | Should |

## Critères d'acceptation (exemple pour US01)
- Étant donné qu'une période est sélectionnée,
  quand j'ouvre la page Funnel,
  alors je vois le nombre de sessions pour chaque étape, dans l'ordre du parcours.
- Le total de la première étape est supérieur ou égal à celui de la dernière.
